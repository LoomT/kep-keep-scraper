# Parsing YAML in Kotlin

There are several solid options for turning a raw YAML string into a structured object in Kotlin. Here are the most common ones, roughly ordered by how idiomatic they are for Kotlin projects.

## 1. `kotlinx.serialization` + YAML (recommended for Kotlin)

Since your file already uses `kotlinx.serialization.json`, the most consistent choice is [`kaml`](https://github.com/charleskorn/kaml), which plugs directly into `kotlinx.serialization`.

**Gradle:**
```kotlin
plugins {
    kotlin("plugin.serialization") version "2.3.0"
}
dependencies {
    implementation("com.charleskorn.kaml:kaml:0.110.0")
}
```

**Typed decoding into a data class:**
```kotlin
import com.charleskorn.kaml.Yaml
import kotlinx.serialization.Serializable

@Serializable
data class KepYaml(
    val title: String,
    val authors: List<String> = emptyList(),
    val status: String? = null,
    val owningSig: String? = null,
)

val kep: KepYaml = Yaml.default.decodeFromString(KepYaml.serializer(), yamlContent)
```

**Untyped / dynamic decoding** (useful when the schema varies, like KEP yamls do):
```kotlin
import com.charleskorn.kaml.Yaml
import com.charleskorn.kaml.YamlNode

val node: YamlNode = Yaml.default.parseToYamlNode(yamlContent)
val title = node.yamlMap.get<YamlNode>("title")?.yamlScalar?.content
```

You can also convert it straight into a `JsonElement` from `kotlinx.serialization.json` if you want to keep everything as JSON downstream:
```kotlin
import com.charleskorn.kaml.Yaml
import kotlinx.serialization.json.JsonElement

val asJson: JsonElement = Yaml.default.decodeFromString(JsonElement.serializer(), yamlContent)
```

## 2. SnakeYAML (the classic Java library)

The most battle-tested option on the JVM. Zero Kotlin-specific features, but very flexible.

**Gradle:**
```kotlin
dependencies {
    implementation("org.yaml:snakeyaml:2.3")
}
```

**Untyped:**
```kotlin
import org.yaml.snakeyaml.Yaml

val yaml = Yaml()
val data: Map<String, Any?> = yaml.load(yamlContent)
val title = data["title"] as? String
```

**Typed (via JavaBeans):**
```kotlin
val parsed: KepYaml = Yaml().loadAs(yamlContent, KepYaml::class.java)
```

There is also **SnakeYAML Engine** (`org.snakeyaml:snakeyaml-engine`), which is the YAML 1.2-only, modernised fork.

## 3. Jackson with the YAML module

Great if you already use Jackson, or if you want to convert YAML ↔ JSON trees easily.

**Gradle:**
```kotlin
dependencies {
    implementation("com.fasterxml.jackson.dataformat:jackson-dataformat-yaml:2.18.0")
    implementation("com.fasterxml.jackson.module:jackson-module-kotlin:2.18.0")
}
```

**Usage:**
```kotlin
import com.fasterxml.jackson.databind.ObjectMapper
import com.fasterxml.jackson.dataformat.yaml.YAMLFactory
import com.fasterxml.jackson.module.kotlin.registerKotlinModule
import com.fasterxml.jackson.module.kotlin.readValue

val mapper = ObjectMapper(YAMLFactory()).registerKotlinModule()

// Typed
val kep: KepYaml = mapper.readValue(yamlContent)

// Untyped tree
val tree = mapper.readTree(yamlContent)
val title = tree.get("title")?.asText()
```

## Which one should you pick?

| Library | Best when |
|---|---|
| **kaml** | You already use `kotlinx.serialization` (this is your case). Idiomatic Kotlin, multiplatform-friendly. |
| **SnakeYAML** | You need maximum control, custom tags, or low-level event/stream parsing. |
| **Jackson YAML** | You already use Jackson elsewhere, or want unified JSON+YAML handling via `JsonNode`. |

Given your file is using `kotlinx.serialization.json` and `JsonObject`, **kaml** will fit the most naturally — and you can even decode YAML directly into a `JsonObject`/`JsonElement` so the rest of your pipeline keeps working with `getJsonString(...)` style helpers unchanged.
