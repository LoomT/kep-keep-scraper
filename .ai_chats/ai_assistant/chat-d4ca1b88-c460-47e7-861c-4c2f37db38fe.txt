# Creating a Zip Archive of a Git Repository (Excluding Ignored Files)

Git has a built-in command `git archive` that creates an archive containing only the files tracked by Git. This automatically excludes:
- Files listed in `.gitignore`
- Untracked files
- The `.git` directory itself

## Basic Usage

```bash
git archive --format=zip --output=repo.zip HEAD
```

This creates `repo.zip` from the current `HEAD` commit.

## Common Variations

**Archive a specific branch:**
```bash
git archive --format=zip --output=repo.zip main
```

**Archive a specific tag/commit:**
```bash
git archive --format=zip --output=repo-v1.0.zip v1.0
```

**Archive only a subdirectory:**
```bash
git archive --format=zip --output=src.zip HEAD src/
```

**Add a prefix folder inside the zip** (useful so files extract into a folder rather than the current directory):
```bash
git archive --format=zip --prefix=myproject/ --output=repo.zip HEAD
```

**Create a tar.gz instead:**
```bash
git archive --format=tar.gz --output=repo.tar.gz HEAD
```

## Excluding Additional Files

If you want to also exclude some tracked files (e.g., `.gitignore` or CI configs) from the archive, use `export-ignore` in a `.gitattributes` file:

```text
.gitignore export-ignore
.github/ export-ignore
tests/ export-ignore
```

Then run `git archive` as usual — those entries will be omitted.

## ⚠️ Important Caveat

`git archive` only includes **committed** files. If you have uncommitted changes or new untracked files (that aren't ignored), they will **not** be in the zip. Commit (or stash) first if you need them included.

## Alternative: Using `git ls-files` with `zip`

If you want to include **uncommitted (but not ignored)** working-tree files:

```bash
zip repo.zip $(git ls-files --cached --others --exclude-standard)
```

This zips all tracked + untracked files while still respecting `.gitignore`.
